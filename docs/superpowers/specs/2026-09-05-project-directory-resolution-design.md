# cli-novel-writer 项目目录解析设计

日期：2026-09-05
状态：已获用户确认

## 背景与目标

当前 `cli-novel-writer` skill 的所有产出（`叙事宪法.md`、`世界规则白皮书.md`、`人物档案.json`、`伏笔台账.md`、`章节目录.md`、章节正文 `第N章-vX.md`）都按「本地存储规范」建在工作目录下 `outputs/日期-项目名/`。问题：

- 目录有 `outputs/` 一层冗余，且非用户显式选择。
- 用户若想自定义项目位置（例如独立的 `novels/我的小说/` 或指定绝对路径 `D:\novels\xxx`），现有的 SKILL.md 没有为该场景提供任何规则——既不解析、也不记录、续写更找不到。

本次落地：**让 skill 支持用户指定项目根目录**（绝对/相对路径均可），未指定时默认建在 cwd 下 `日期-项目名/`（去掉 `outputs/` 层），并记录项目位置供跨会话续写回查。

## 已确认的设计决策

1. **指定目录 = 项目根**：`叙事宪法.md`/`人物档案.json`/`第1章-v1.md` 等直接建在指定目录下，不再追加 `日期-项目名` 层。
2. **默认规则 = 直接建在 cwd**：未指定 → `cwd/日期-项目名/`（删除原「若已有 outputs 则放 outputs」逻辑）。
3. **路径解析支持：相对 + 绝对 + `~`**（相对 cwd；`~` 展开主目录；Windows 盘符/UNC 绝对；macOS/Linux `/` 开头绝对）。环境变量不展开。
4. **跨会话回查**：项目根内落 `项目索引.md`，记录项目名/创建日期/绝对项目根路径；续写时先在 cwd 找 `项目索引.md`，找不到再问用户。
5. **与三个集成点协同**：派单协议（路径从项目根展开）、本地存储规范（重写）、启动流程（新增第零步）。

## 架构总览

```
在 cwd 下加一个 .gitignore 可忽略的运行时文件（可选，见 §跨平台注意）
项目目录结构（项目根 = 解析出的目录）：
├─ 项目索引.md            元数据：项目名 / 创建日期 / 项目根（绝对路径）
├─ 叙事宪法.md            核心冲突、禁用项、硬性约束
├─ 世界规则白皮书.md      物理法则、地理、货币、种族、战力天花板与差值
├─ 人物档案.json          按 Schema 存每个角色
├─ 伏笔台账.md            伏笔埋设/回收状态表
├─ 章节目录.md            每章最新版本 + 一句话梗概
└─ 第N章-vX.md            章节正文（带版本号）
```

## §1 路径解析规则

### 输入

启动流程第零步获取用户对「项目目录」的指定（字符串）；缺省则视为未指定。

### 解析顺序（一次判定，命中即止）

1. **以 `~` 开头**（`~` 或 `~/xxx`）→ 展开用户主目录（跨平台）。
2. **绝对路径** → 直接使用。
   - Windows 绝对：以盘符（`C:` 等，含 `C:\`/`C:/`）或 `\\`（UNC）开头。
   - macOS/Linux 绝对：以 `/` 开头。
3. **相对路径** → 以 cwd 为基准拼接，并做路径规范化（消除 `.`/`..` 片段）。
   - Windows 相对：以 `\` 或 `/` 分隔均可；也接受 `.\`、`..\`、`./`、`../` 前缀。
   - macOS/Linux 相对：以 `/` 分隔；接受 `./`、`../` 前缀。
4. **空 / 未指定** → 默认 `cwd/日期-项目名/`（日期为当天，格式 `YYYY-MM-DD`；项目名取自用户题材/梗概或其提供）。

### 跨平台判定表（给模型，无需运行时 os 检测）

| 输入形式 | Windows 判定 | macOS/Linux 判定 |
|---|---|---|
| `~` / `~/xxx` | 主目录（绝对） | 主目录（绝对） |
| `C:\x`、`C:/x`、`\\srv\x` | 绝对 | 视为相对（罕见）→ 拼 cwd |
| `/x` | 相对（`/` 开头非盘符） | 绝对 |
| `x\y`、`.\x`、`..\x` | 相对（反斜杠分隔） | 视为相对 → 拼 cwd |
| `x/y`、`./x`、`../x` | 相对 | 相对 |

**要点**：
- 相对/绝对判定**只看输入字符串特征**，不依赖「当前 OS」猜测——规则表对 win 与 mac/linux 各列一套，模型按所在平台取对应列。
- `..`（`../` 或 `..\`）允许跨层级回退并在规范化的解析路径中保留；规范化后若超出文件系统根则报错并请用户修正。
- 「用户是否指定目录」的判定：仅以**用户明确说「未指定 / 不指定 / 随便」或只给题材未提路径**为准 → 走默认 `cwd/日期-项目名/`。只要用户给了**任意路径字符串**（相对/绝对/`~`，即使形如 `2026-09-05-书名`）→ 按本表解析并作为项目根。

> 注：原「若工作目录已有 outputs 目录则放进 outputs」逻辑删除——不再有 `outputs/` 层。

## §2 跨会话回查（项目索引.md）

**文件**：项目根下 `项目索引.md`，由启动流程第零步创建（若不存在）。

```markdown
# 项目索引
- 项目名：
- 创建日期：YYYY-MM-DD
- 项目根目录：（绝对路径）
- 状态文件名：叙事宪法.md / 世界规则白皮书.md / 人物档案.json / 伏笔台账.md / 章节目录.md / 第N章-vX.md
```

**写入规则**：`项目根目录` 字段一定写**绝对路径**（win: `C:\...`，unix: `/...`），即便用户当初给的是相对路径——这样换 cwd 后仍能唯一回查。

**回查规则**（用户说「继续上次小说 / 续写」时）：
1. 先在 **cwd** 找 `项目索引.md`；找到 → 以其 `项目根目录` 为项目根。
2. 找不到 → 问用户「上次项目目录在哪？」，用户给指即用。
3. 若用户指定了新路径且该路径下已有 `项目索引.md` → 直接重用该索引继续（视为「继续该项目」）。

**副作用**：`项目索引.md` 是项目的一部分，随项目走；不入 git（若项目在 git 仓库下，`.gitignore` 可选加 `projects/` 或按需）。

## §3 与现有 SKILL.md 的集成点

### 3.1 派单协议（SKILL.md:14-16, 26）

新增一条原则：「数据来源 / 产出写回」路径一律**从项目根展开**；项目根由启动流程已解析（用户指定或默认），子代理只按给定路径读写，不自行推断目录。

### 3.2 本地存储规范（SKILL.md:68-77）

重写为：

> **项目根目录**（所有项目文件所在目录）解析规则：
> - 用户指定 → 该路径作为项目根（绝对路径直接用；相对路径以 cwd 展开；`~` 展开主目录）；判定规则见 §1。
> - 未指定 → `cwd/日期-项目名/`（日期 `YYYY-MM-DD`）。
> 项目根下直接存放：`项目索引.md`、`叙事宪法.md`、`世界规则白皮书.md`、`人物档案.json`、`伏笔台账.md`、`章节目录.md`、`第N章-vX.md` 章节正文。

### 3.3 启动流程（SKILL.md:101-107）

新增**第零步**（在三步走之前）：
> 第零步：解析项目根目录（用户指定或默认，规则见「本地存储规范」）→ 创建目录 → 若已有 `项目索引.md` 则读回作为「继续」；否则新建 `项目索引.md` 并写入项目名/创建日期/绝对根路径。此后所有派单路径都从项目根展开。

### 3.4 README.md

「它会读写文件」一节同步更新为项目根模型（去掉 outputs 层、加入 `项目索引.md`、说明支持指定目录）。

### 3.5 CLAUDE.md

「Project output」一段同步：改为项目根 + `项目索引.md` 回查。

## §4 边界与不做的事

- **不做环境变量展开**（`$VAR` / `%VAR%`）。`~` 是唯一支持的展开。
- **不做缓存/多项目并行管理**：一次会话只管一个项目；`项目索引.md` 定位当前项目。
- **不强制 `outputs/`**：完全删除该层（迁移说明见 §5）。
- **不改 `scripts/count_cjk.py` 及测试**：路径解析在 skill 文本（模型执行）层，不引入 Python 逻辑。
- **不新增 Python 脚本**：目录解析/建目录/写索引都由队长文本执行。

## §5 迁移与兼容

- 已有项目（在 `outputs/日期-项目名/` 下的）迁移路径：把 `项目索引.md` 写进该目录（或在续写时在对应目录手动放一个），即可按新规则继续；不强制移动文件。
- 原「若已有 outputs 则放进 outputs」行为废弃——新项目一律按解析规则落在用户指定或 `cwd/日期-项目名/`。

## 测试与验证

- 纯文本/模型层变更，无 Python 测试。
- 验证方式（手动演练）：
  1. 用相对路径指定：`novels/我的小说`（win）→ 解析为 `cwd/novels/我的小说`，建目录 + 索引。
  2. 绝对路径：`D:\novels\书名`（win）/ `/home/u/novels/书名`（unix）→ 直接用。
  3. `~` 路径：`~/novels/书名` → 展开主目录。
  4. 未指定 → `cwd/2026-09-05-书名/`。
  5. 续写：cwd 有 `项目索引.md` → 找回；无 → 问用户。
- 语法/路径校验：确认 SKILL.md 内链接与新路径可解析。

## 维护原则（沿用）

- 不把细节再塞回主 SKILL.md；新增规则落在本地存储规范与启动流程。
- 路径解析规则只此一处定义（本地存储规范），其他文件引用它。
- 跨平台判定表是唯一权威，模型不需要运行时 OS 检测。
