# 剧情推演落盘（plot-state persistence）设计

日期：2026-09-06

## 背景与问题

本技能「数据靠文件传」的铁律（`SKILL.md`）只覆盖了**静态设定**（宪法/白皮书/人物/台账/章节目录），而**剧情动态状态**没有文件承载：

- 剧情子代理用「节点法」规划的主线节点、支线、转折点、情绪心电图、"因为…所以…"因果链，只存在于多次派单的**对话流转**中。
- 子代理每次派单是**全新上下文**（`SKILL.md:12`「子代理没有你的对话记忆」）——大纲只活在对话里，跨派单即丢。
- `SKILL.md:68`「每完成 3–5 章复盘校准**后续大纲**」——校准对象（后续大纲）根本没落盘，校准=重建。
- 复核判「逻辑断链/情绪断裂」靠读全部历史正文 + 台账，无「已发生剧情事实」清单可对照，费时易漏。

**根因**：剧情动态状态（已发生什么、接下来打算怎么走、为什么）未被视为一等公民持久化。上下文一压缩/换会话，剧情规划归零。

## 目标

把剧情动态状态落盘为项目根的权威文件 `剧情推演.md`，防上下文丢失，供文笔/复核/续写/导入使用。

## 决策记录

| # | 决策 | 选项 | 结论 |
|---|---|---|---|
| 1 | 文件形态 | A 单一 `剧情推演.md` / B 多文件细分 / C 并入台账 | **A 单一文件**（一文件一责任） |
| 2 | 更新时机 | A 每章定稿后 / B 并 3–5 章刷新 / C 队长自更 | **A 每章定稿后** |
| 3 | 外来导入 | 导入时是否推导 | **推导**，标注「从原章节推导」，与宪法等同批产出确认 |
| 4 | 文笔/复核读入 | 是否读入 | **读入**（文笔把握情绪节奏，复核对照事实链） |
| 5 | 谁更新 | A 派剧情 / B 队长执笔 / C 关键事件才触发 | **A 每章必派剧情子代理增量更新**（串行） |

## 文件模板（`剧情推演.md` 四块）

```markdown
# 剧情推演

## 剧情现状（事实链）
| 节点 | 章号 | 事件 | 因果（因为…所以…） |
|------|------|------|---------------------|
| 1 | 3 | 张澈发现妹妹旧发绳 | 因为废墟中发现旧发绳且未见尸骨，所以他燃起偏执的希望 |
| 2 | 5 | 与城主结盟 | 因为需要城防资金，所以接受城主条件 |

## 情绪心电图
| 人物 | 处境 | 情绪走线 | 变化触发点 |
|------|------|----------|------------|
| 张澈 | 被通缉 | 绝望→偏执希望 | 3章末发现遗物 |

## 支线与矛盾
- 支线：城主背后的走私网（伏笔 F-007）
- 主线矛盾：复仇 vs 生存

## 后续计划（滚动）
- [ ] 回收 F-003 伏笔（6章）
- [ ] 触发转折：妹妹被目击在城北
```

## 增量更新纪律（铁律级）

- 只追加、不改写既定事实：已发生节点不得被后续派单覆盖。
- 已发生节点 = **只增行**；变动只发生在「后续计划」「情绪心电图当前态」「支线状态」。
- 确需修订已发生节点 → 用「修订注释：旧值→新值，理由」追加，不静默改写。

## 生命周期

- **新开（A 路）**：第一步联席会产出宪法草案/白皮书大纲时，剧情子代理一并产 `剧情推演.md` 初版（主线首段节点 + 初始情绪心电图 + 初始矛盾/支线）——与草案同批确认。
- **每章定稿后**：队长派剧情子代理增量更新（读最新章 + 现有推演 + 台账 → 追加事实行 / 更新当前态 / 修订后续计划）。串行，不并行。
- **导入（C 路）**：导入流程第 2 步剧情子代理一并推导 `剧情推演.md`（标「从原章节推导」，随草案同批确认）。
- **续写（B 路）**：回查后读 `剧情推演.md` 作为剧情状态入口（同 `章节目录.md` 定位逻辑）。
- **全局刷新（3–5 章）**：现有复盘校准流程新增「读推演 → 校准后续计划」一步。
- **文笔/复核读入**：文笔写本章前读「剧情现状末行 + 情绪心电图 + 相关后续」；复核判「逻辑断链/情绪断裂/身体信息状态」对照「剧情现状」事实链 + 伏笔台账。
